## 🔑 Key Information at a Glance

### Installation
```bash
cd /Users/honeyreddy/IdeaProjects/Csp-project
npm install
npm run build
npm start
```

### Access Website
```
http://localhost:5000
```

### Available Commands
```bash
npm start              # Production server
npm run dev           # Vite dev server
npm run dev:server    # Backend with hot reload
npm run build         # Build frontend
npm run preview       # Preview build
```

### Pages Available
- Home: `/`
- About: `/about`
- Technology: `/technology`
- Dashboard: `/dashboard`
- Gallery: `/gallery`
- Contact: `/contact`

### API Endpoints
```
GET  /api/project
GET  /api/technology
GET  /api/dashboard
GET  /api/sensor-history/:id
GET  /api/gallery
POST /api/contact
```

### Tech Stack
- **Frontend:** React 18, Vite, Chart.js
- **Backend:** Node.js, Express
- **Styling:** CSS3 with animations
- **Database:** Mock data (ready for integration)

### Deployment Options
- Heroku (easiest)
- DigitalOcean
- AWS EC2
- Netlify (frontend)
